# ملفات خلود — دورة AI

واجهة عربية حديثة لإدارة واستعراض ملفات دورة الذكاء الاصطناعي، بتصميم RTL وألوان نارية مستوحاة من التعلّم والطاقة. تشمل الواجهة البحث، العرض الشبكي والقائمة، التحديد المتعدد، مؤشرات التخزين، وملخصات الدروس مع معاينة سريعة.

## تشغيل محلي

```bash
pnpm install
pnpm dev
```

## النشر

يتم بناء النسخة الثابتة تلقائيًا عبر GitHub Actions ونشرها على GitHub Pages عند كل push إلى فرع `main`.

> نسخة GitHub Pages تعرض الواجهة الثابتة وبيانات العرض التجريبية. ربط Google Drive الفعلي يحتاج إضافة OAuth وDrive API على خادم آمن.
